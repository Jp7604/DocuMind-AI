# Privacy Policy (Draft)

This document is a draft and should be reviewed before production launch.

DocuMind AI processes uploaded PDF files and related prompts to provide retrieval and question-answering functionality. The system may temporarily store document text, chunk metadata, and generated answers in memory or local app storage depending on deployment configuration.

Typical data handling may include:
- uploaded PDF files for indexing;
- extracted text and chunk embeddings used for retrieval;
- prompts and generated responses for the user’s current session;
- API keys and environment variables stored outside the repository.

DocuMind AI is not intended to be used for sensitive personal data unless the deployment includes a separate compliance review and storage controls. Logs, access events, and AI provider usage may be retained according to the host environment and the configured provider policies.

This draft is not a final legal commitment and should be reviewed by counsel before launch.
